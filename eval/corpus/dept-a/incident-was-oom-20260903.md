# 장애 보고서: was-prd-02 메모리 부족(OOM) 오류 (2026-09-03)

## 개요
- 문서번호: INC-2026-072
- 장애 등급: 3등급
- 발생: 2026-09-03 10:05
- 복구: 2026-09-03 10:23
- 복구 시간: 18분
- 영향 시스템: 그룹웨어 누리웍스 (was-prd-02)
- 담당: 한지우

## 현상
오전 10:05부터 그룹웨어 누리웍스의 로그인이 지연되다가 10:09에는 로그인 화면에서 오류가 발생하였다. was-prd-02의 자바 프로세스가 OutOfMemoryError를 출력하고 다운되었으며 이중화된 was-prd-01이 모든 요청을 떠안아 응답이 느려졌다. 장애 시간 동안 약 350명의 사용자가 영향을 받았다.

## 원인
월말 정산 시즌의 전자결재 조회 증가와 세션 객체가 해제되지 않는 코드 문제가 겹쳐 힙 메모리가 가득 찼다. 힙 설정은 4GB였다.

## 조치
1. was-prd-02 프로세스를 재시작하여 10:23에 서비스를 복구하였다.
2. 힙 메모리를 4GB에서 8GB로 증설하였다 (서버 물리 메모리 32GB 중 8GB 할당).
3. 세션 타임아웃을 60분에서 30분으로 단축하였다.
4. 세션 누수 코드는 개발 업체에 수정을 요청하여 2026-09-18에 패치가 배포되었다.

## 재발 방지
- 힙 사용률 80% 도달 시 경보를 발송한다.
- 월말 정산 기간(매월 25일부터 말일까지)에는 WAS 상태를 하루 2회 점검한다.
- 이 서버의 OS 보안 패치는 2026년 10월 10일 작업 대상에 포함된다.
