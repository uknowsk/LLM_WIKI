# [점검 공지] 전산실 UPS 배터리 교체 작업 (2026-08-02)

## 개요
전산실 무정전 전원장치(UPS) 배터리의 사용 연수가 5년을 넘어 일괄 교체한다. 교체 대상 배터리는 총 32개이며, 교체 비용은 1,850만원이다.

## 일정
- 일시: 2026-08-02 (일) 09:00 ~ 13:00 (4시간)
- 작업: 협력업체 에너지솔 기술자 3명, 인프라팀 최민재 입회
- 정전: 없음 (우회 전환 방식)

## 작업 방식
1. 09:00 UPS 우회(바이패스) 전원으로 전환한다. 이 시간 동안 서버는 일반 상용 전원으로 동작한다.
2. 09:30 배터리 캐비닛 A동 16개 교체
3. 11:00 배터리 캐비닛 B동 16개 교체
4. 12:30 UPS 정상 모드로 복귀 후 방전 시험(10분)
5. 13:00 작업 완료 보고

## 유의 사항
- 우회 전환 중에 상용 전원 장애가 발생하면 서버가 순간 정전될 수 있으므로 해당 시간 전후로 한전 정전 예고 여부를 확인하였다.
- 작업 중 전산실 온도는 평소 22도 수준을 유지한다.
- 교체한 배터리는 폐기 업체가 반출한다.

## 사전 조치
- 8월 1일 중요 서버 백업 완료 확인
- 주요 서버 전원 이중화 상태 확인
- 비상 연락망: 최민재 (내선 4420)

## 결과
작업은 예정보다 20분 빠른 12:40에 완료되었고 방전 시험은 정상이었다.
