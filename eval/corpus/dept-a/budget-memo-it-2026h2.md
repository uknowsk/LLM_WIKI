# [메모] 2026년 하반기 IT 인프라 예산 계획

- 작성일: 2026-07-20
- 작성: 김서연, 승인: 오세훈 팀장
- 수신: 임수정 본부장

## 1. 총괄
2026년 하반기(7~12월) IT 인프라 예산은 총 6억 2,000만원이다. 이 중 항목별 계획은 5억 9,000만원이며, 예비비 3,000만원을 별도로 편성한다.

## 2. 항목별 예산
| 항목 | 금액 | 비고 |
|---|---|---|
| 서버 교체 | 2억 3,000만원 | 노후 서버 8대 교체 |
| 보안(SIEM) | 1억 5,000만원 | 하반기 집행분 |
| 네트워크 | 9,000만원 | 스위치, 무선 AP |
| 클라우드 이전 | 1억 2,000만원 | ERP DB 이전 용역 |
| 예비비 | 3,000만원 | 장애 대응용 |

## 3. 집행 원칙
- 1,000만원 이상 지출은 사전에 팀장의 승인을 받는다.
- 5,000만원 이상은 본부장 승인과 3개 업체 비교 견적이 필요하다.
- 월별 집행 계획은 별도 엑셀 예산표를 따른다.

## 4. 참고 사항
- 클라우드 이전 항목은 7월 시점 계획이며 8월 10일 주간회의 결정 이전에 편성되었다.
- 누리메일 서버 이전 비용 4,200만원은 네트워크와 별도로 운영 예산에서 지출한다.
- 해든DB 라이선스 갱신 금액은 2027년 예산에 반영하며 하반기에는 지출이 없다.

## 5. 일정
예산 계획은 7월 말까지 본부장 승인을 받고, 이후 분기마다 집행 현황을 보고한다.

※ 이 메모는 인프라팀 예산이며 전사 경비 예산과 구분된다.
